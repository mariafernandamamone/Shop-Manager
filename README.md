# Shop Manager CLI System

A terminal-based shopping cart and user management application built using **Node.js**. This project was developed to master foundational programming concepts, focusing on 2D array matrices, matrix indices `[i][j]`, primitive data types, custom modular logic, and interactive CLI loops.

---

## 🌟 Key Features

- **Product Catalog Management**: View item catalog dynamically formatted from 2D matrices.
- **Cart Operations**: Add products with quantity checks, view itemized cart subtotals, remove individual items, or clear the cart.
- **Checkout & Disclosures**: Calculate final purchase totals including subtotal and discount code application (`DESCUENTO10`).
- **User Management**: Display active user directory and register new users with multi-prompt terminal inputs.
- **Interactive Terminal UI**: Seamless navigation using Node.js `readline` interface.

---

## 🛠️ Built With

- **JavaScript (ES6+)**
- **Node.js Core Modules**: `readline`
